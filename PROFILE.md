# anew

A stateless "page-in-a-URL" service that encodes a self-contained HTML document into a shareable, immutable URL (HTML → URL) and reads it back (URL → HTML). No account, no hosting; free, deterministic, and unauthenticated. Exposes a REST/HTTP API, a hosted MCP server, an A2A agent, and llms.txt.

- **Provider:** https://anew.page
- **Documentation:** https://anew.page/llms.txt
- **Base URL:** https://anew.page
- **Tags:** html, webpage, website, url, encode, share, web-publishing, developer-tools, mcp, a2a, ai-agent-tooling
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** yes
- **Confidence:** 97/100

## APIs

- **anew Write/Read API** — REST/HTTP API to encode self-contained HTML into shareable URLs (POST /write) and read pages back (GET /{slug}), with OpenAPI 3.1.1 contract. Unauthenticated and free. (`https://anew.page`)

> Multiple confirmed public interfaces: REST/HTTP API with OpenAPI 3.1.1 (https://anew.page/openapi.json), a hosted remote MCP server at https://anew.page/mcp (streamable-http; tools anew_write and anew_read; server card at https://anew.page/.well-known/mcp/server-card.json and manifest at https://anew.page/.well-known/mcp.json), an A2A agent at https://anew.page/a2a/v1 with Agent Card at https://anew.page/.well-known/agent-card.json and published skills (write/read), and a public llms.txt. An RFC 9727 api-catalog is at https://anew.page/.well-known/api-catalog. The llms.txt documents a local-mint fallback (brotli+base64url) for environments that cannot POST — this is a client-side technique, not a hosted service. The provider's advertised apis.json at https://anew.page/apis.json was not fetchable during research. All interfaces are unauthenticated and free; no AsyncAPI, GraphQL, or Postman collection published.
